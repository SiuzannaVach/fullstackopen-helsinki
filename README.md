# Full Stack Open — University of Helsinki 🇫🇮

This repository contains my solutions and projects for the renowned **Full Stack Open** course provided by the University of Helsinki. 

The goal of this course is to deep-dive into modern JavaScript-based web development and master production-grade Full-Stack architecture.

## 🚀 Learning Roadmap & Progress

- [ ] **Part 0:** Fundamentals of Web apps (HTTP, AJAX, Single Page Apps)
- [ ] **Part 1:** Introduction to React
- [ ] **Part 2:** Communicating with server (REST APIs, Axios)
- [ ] **Part 3:** Programming a server with NodeJS and Express
- [ ] **Part 4:** Testing Express servers, user administration
- [ ] **Part 5:** Testing React apps (Jest, Cypress)
- [ ] **Part 6:** Advanced State Management (Redux, Thunk)
- [ ] **Part 7:** React Router, custom hooks, styling app with CSS and webpack
- [ ] **Part 8:** GraphQL
- [ ] **Part 9:** TypeScript
- [ ] **Part 11:** CD/CD (Docker, GitHub Actions)
- [ ] **Part 12:** Containers (Docker)
- [ ] **Part 13:** Relational Databases

## 🛠 Tech Stack Used
- **Frontend:** React, Redux, TypeScript
- **Backend:** Node.js, Express, GraphQL
- **Databases:** MongoDB, PostgreSQL
- **DevOps:** Docker, CI/CD pipelines, Jest/Cypress for testing
